### 基础路径与环境配置

| 环境变量         | 作用说明             | 典型值/示例              |
|:-------------|:-----------------|:--------------------|
| `GOROOT`     | Go 安装根目录         | `/usr/local/go`     |
| `GOPATH`     | 工作区目录（源码、依赖、二进制） | `~/go`              |
| `GOBIN`      | 编译生成的可执行文件存放目录   | `~/go/bin`          |
| `GOCACHE`    | 编译缓存目录（用于加速构建）   | `~/.cache/go-build` |
| `GOMODCACHE` | 模块依赖的本地缓存目录      | `~/go/pkg/mod`      |
| `GOENV`      | Go 环境配置文件路径      | `~/.config/go/env`  |

### 交叉编译（目标平台与架构）

| 环境变量        | 作用说明                                   | 可选值                                                          |
|:------------|:---------------------------------------|:-------------------------------------------------------------|
| `GOOS`      | 目标操作系统                                 | `linux`, `windows`, `darwin`, `freebsd`, `js`(wasm) 等        |
| `GOARCH`    | 目标 CPU 架构                              | `amd64`, `arm64`, `386`, `arm`, `ppc64le`, `s390x`, `wasm` 等 |
| `GOARM`     | ARM 架构版本 (仅当 `GOARCH=arm`)             | `5`, `6`, `7`                                                |
| `GOARM64`   | ARM64 微架构级别                            | `v8.0`, `v8.1`, `v8.2`, `v9.0` 等 (Go 1.22+)                  |
| `GOMIPS`    | MIPS 浮点/软浮点 (当 `GOARCH=mips`/`mipsle`) | `hardfloat`, `softfloat`                                     |
| `GOMIPS64`  | MIPS64 浮点设置                            | `hardfloat`, `softfloat`                                     |
| `GOPPC64`   | PowerPC 架构级别                           | `power8`, `power9`, `power10`                                |
| `GOWASM`    | WebAssembly 特性开关                       | `satconv`, `signext` (多个用逗号分隔)                               |
| `GOAMD64`   | AMD64 微架构级别 (Go 1.17+)                 | `v1`, `v2`, `v3`, `v4`                                       |
| `GORISCV64` | RISC-V 64 特性                           | 实验性                                                          |

### 模块与依赖管理

| 环境变量          | 作用说明                           | 典型值/示例                         |
|:--------------|:-------------------------------|:-------------------------------|
| `GO111MODULE` | 启用/禁用模块支持                      | `auto`, `on`, `off`            |
| `GOPROXY`     | 模块代理 URL（支持逗号分隔，`direct` 表示直连） | `https://goproxy.cn,direct`    |
| `GOSUMDB`     | 校验和数据库（验证模块完整性）                | `sum.golang.org`, `off`        |
| `GOPRIVATE`   | 私有模块模式（同时跳过代理和校验和）             | `*.corp.com,git.mycompany.com` |
| `GONOPROXY`   | 不使用代理的模块路径（通常与 `GOPRIVATE` 同值） | 同上                             |
| `GONOSUMDB`   | 不使用校验和的模块路径                    | 同上                             |
| `GOVCS`       | 限制特定模块路径使用的版本控制工具              | `public:git                    |

### CGO 与链接相关

| 环境变量           | 作用说明                | 典型值                |
|:---------------|:--------------------|:-------------------|
| `CGO_ENABLED`  | 是否启用 CGO            | `1` (启用), `0` (禁用) |
| `CGO_CFLAGS`   | 传递给 C 编译器的标志        | `-g -O2`           |
| `CGO_CPPFLAGS` | 传递给 C 预处理器标志        | 用户自定义              |
| `CGO_CXXFLAGS` | 传递给 C++ 编译器标志       | `-g -O2`           |
| `CGO_FFLAGS`   | 传递给 Fortran 编译器标志   | `-g -O2`           |
| `CGO_LDFLAGS`  | 传递给链接器标志            | 用户自定义              |
| `GOGCCFLAGS`   | 生成的实际 C 编译器调用参数（只读） | 自动组合生成             |

### 实验特性 (Go 1.18+ 逐步引入，未来可能变化)

| 环境变量                 | 作用说明                | 状态/备注                         |
|:---------------------|:--------------------|:------------------------------|
| `GOEXPERIMENT`       | 启用一组实验性语言/运行时/编译器特性 | 可设多个，用逗号分隔，如 `loopvar,arenas` |
| - `loopvar`          | 修正 `for` 循环变量捕获语义   | 预计 Go 1.22 正式转正               |
| - `arenas`           | 内存竞技场（手动内存管理）       | 实验性，不保证持续                     |
| - `regabi`           | 基于寄存器的调用约定          | 已部分默认启用                       |
| - `heapdump`         | 自定义堆转储格式            | 实验性                           |
| - `coverageredesign` | 代码覆盖率重设计            | 实验性                           |

> **注意**：`GOEXPERIMENT` 的具体可用子项随 Go 版本变化，请通过 `go doc goexperiment` 或 `go env` 查看当前版本支持哪些。

### 调试、日志与行为控制

| 环境变量          | 作用说明                 | 典型值                               |
|:--------------|:---------------------|:----------------------------------|
| `GODEBUG`     | 控制运行时调试选项（垃圾回收、调度器等） | `gctrace=1`, `schedtrace=1000`    |
| `GOGC`        | 垃圾回收目标百分比（调优内存/CPU）  | `100` (默认)，调大降低 GC 频率             |
| `GOMEMLIMIT`  | Go 内存软限制（Go 1.19+）   | `8GiB`                            |
| `GOTRACEBACK` | 控制 panic 时的栈回溯详细程度   | `none`, `single`, `all`, `system` |
| `GORACE`      | 数据竞争检测器参数            | `history_size=7`                  |
| `GOFIPS140`   | 是否启用 FIPS 140-2 加密模式 | `on`, `off` (部分企业版支持)             |
| `GOEXE`       | 可执行文件后缀（系统只读）        | `.exe` (Windows) / 空 (Unix)       |

### 构建与编译标志（全局默认值）

| 环境变量        | 作用说明                            | 示例                    |
|:------------|:--------------------------------|:----------------------|
| `GOFLAGS`   | 给 `go` 命令传递的默认标志                | `-v -x -mod=readonly` |
| `GOGOFLAGS` | 给 `go tool compile` 的额外参数（内部使用） | 一般无需设置                |
